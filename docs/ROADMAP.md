# Activity Log for Admins, feature roadmap

Updated 17 November 2026.

## Goal

Offer the complete practical feature set documented by WP Activity Log, with every plugin feature available free. Keep the modern investigation workflow, local first storage, and privacy controls that distinguish Activity Log for Admins.

The supported minimum remains WordPress 6.9 and PHP 8.3. We will not spend product effort supporting older releases.

This roadmap compares the Activity Log for Admins 1.2.0 pilot with WP Activity Log 5.7.0 and the vendor documentation reviewed on 16 November 2026. Recheck the comparison before each milestone because the vendor feature set can change.

## Product guardrails

1. Every implemented feature is in the free plugin. Do not add license checks, telemetry, or account requirements.
2. Keep retention selected by each site administrator, default to 90 days, and explain the data and purpose choices in Settings.
3. Keep local database storage as the default. External services require explicit setup and must report delivery failures.
4. Do not record passwords, authentication tokens, full request bodies, comment contents, customer contact data, or redirect destinations.
5. Treat IP addresses, user agents, session identifiers, report recipients, and external service credentials as sensitive. Make collection explicit, restrict access, minimize retention, and document each use.
6. A logging failure must not interrupt the WordPress action being observed.
7. Add focused checks for each completed feature. Run the full security, accessibility, performance, compatibility, and end to end suite once before a release is considered complete.
